09 · Palette options

Three directions, same system

Every screen in this kit is built from tokens, so the palette can be swapped without redrawing anything. A · Horizon (recommended) is a cobalt blue with Night Sky and Ember surfaces. B · Teal + Orange keeps continuity with the current app’s teal and orange. C · Dusk Violet is the most expressive and the most “travel-night” option. Each option below shows Trips home and Balances.

A · Horizon — recommended

Neutral, trustworthy blue for actions. Money lives on warm Ember, travel lives on deep Night Sky, so colour tells you which job you’re doing. Reads well in light and dark and gives the strongest contrast for amounts.

B · Teal + Orange — continuity

Closest to the current Flutter theme. Lowest change for existing users; the orange CTA is loud and friendly, but teal plus orange is a common pairing so it feels less distinctive.

C · Dusk Violet — expressive

Most memorable, strongest fit for the Trip Wrapped moments and the dark theme. Violet needs more care for accessibility on small text, so body copy stays on neutral ink.
