At ≥1024px the dock becomes a 248px sidebar, a trip gets its own sidebar (Expenses · Balances · Members · Notes · Chat · Insights) and detail views open in a right-hand panel instead of sheets. Add expense is a centred two-column dialog with a keyboard shortcut (N). Below 1024 the web app falls back to the tablet rail or the phone layout shown earlier.
